# Prompts for Gainsight Copilot

Paste these into Gainsight Copilot. There is nothing to install.

Copilot reads Gainsight. When Staircase is connected, these prompts also use conversation intelligence (sentiment and what the customer said). When it is not connected, the prompt tells Copilot to say so.

You never paste an id. Where a prompt names an account, replace `[customer name]` with the customer.

| Prompt | Use it for |
|---|---|
| [Prep for a call](prep-for-a-call.md) | Before a customer call |
| [How is this account doing?](how-is-this-account.md) | A quick check on one customer |
| [Renewals coming up](renewals-coming-up.md) | Renewals in the next 90 days |
| [Risks across my book](risks-across-my-book.md) | Open risk CTAs, soonest first |
| [Last quarter of activity](last-quarter-of-activity.md) | QBR prep |
| [Draft a VP call note](draft-a-vp-call-note.md) | A chat-only note when an exec is joining |

These prompts do not post to Timeline or send email. The [Claude skills](../skills/) do more of the job when calendar, email, or other tools are connected, and the cards on the cookbook site say what each one writes.

> Part of the [Gainsight AI Cookbook](../../). Sample prompts, not a supported Gainsight product.
