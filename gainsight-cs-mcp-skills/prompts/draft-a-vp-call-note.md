# Draft a VP call note

When an exec is joining a call. This stays in the chat. It does not post to Timeline. Replace [customer name].

Copy the prompt below into Gainsight Copilot.

```text
Draft a short note for my VP joining the [customer name] call: why it matters, objectives, contacts, and risks.
If Staircase is connected, include sentiment and what the customer said on recent calls. If it is not connected, say so.
Do not post or change anything in Gainsight.
If a value is missing, say so. Do not invent numbers.
```
