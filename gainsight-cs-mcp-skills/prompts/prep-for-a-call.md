# Prep for a call

Before any customer call. Replace [customer name].

Copy the prompt below into Gainsight Copilot.

```text
Prep me for my next call with [customer name].
Tell me where the account stands (health, renewal, ARR, stage),
the open risks and CTAs, what happened recently on the timeline,
and 3 questions I should ask.
If Staircase is connected, include sentiment and what the customer said on recent calls. If it is not connected, say so.
If a value is missing, say so. Do not invent numbers.
```
