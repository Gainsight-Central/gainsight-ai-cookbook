# Open CTAs to clean up

Which open CTAs to close and which still need work. Recommendations only. Nothing is closed or reassigned.

Copy the prompt below into Gainsight Copilot.

```text
List my open CTAs.
For each, give the customer, ARR if it is on the account, CTA type, priority, how long it has been open, and days since the last update.
Compare them with recent timeline activity. Flag any that look already done, and any with no update for about 60 days.
Recommend which to close and which still need action. Do not close, edit, or reassign anything.
If Staircase is connected, use what the customer said when deciding whether the work is already done. If it is not connected, say so.
If a value is missing, say so. Do not invent numbers.
```
