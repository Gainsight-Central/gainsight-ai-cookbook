# Expansion signals

Across the book, before growth conversations. No customer name needed. This does not create a CTA, a CSQL, or an email.

Copy the prompt below into Gainsight Copilot.

```text
Where are the expansion opportunities across my book?
For each account with a signal, put community interest, course completions, usage, and sentiment side by side, and label it a product or services opportunity. Name the source of each signal.
For the top account, brief me on health, usage, and stakeholders. If a competitor has come up, show the customer's own adoption data I can use to answer it.
For each account, propose one next step: a CTA, an email draft, or a CSQL for the account manager. If Staircase shows what worked for similar accounts, say so.
If Staircase is connected, include sentiment and quotes. If it is not connected, say so.
Do not create a CTA or a CSQL, or send an email, until I approve.
If a value is missing, say so. Do not invent numbers.
```
