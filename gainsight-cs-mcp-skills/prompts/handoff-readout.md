# 90-day handoff readout

When a deal has closed and you have the post-sales notes. Replace [customer name] and paste the notes. This proposes a plan. It does not create one.

Copy the prompt below into Gainsight Copilot.

```text
Here are the post-sales handoff notes for [customer name]: [paste notes].
Write a one-page exec briefing handoff readout: what we sold, who owns the relationship, the outcomes they expect, the risks, and the open questions.
Then propose a 90-day handoff success plan: objectives, owners, and the first milestones. If a success plan already exists, add to it instead of starting a second one.
Do not create or update anything in Gainsight until I approve.
If Staircase is connected, use the post-sales conversation. If it is not connected, use only the notes I pasted and say so.
If a value is missing, say so. Do not invent numbers.
```
