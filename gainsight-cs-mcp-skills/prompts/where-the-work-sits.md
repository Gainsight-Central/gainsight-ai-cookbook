# Where the work sits

For a CS leader looking at the team, not one CSM's Monday list. No customer name needed. This does not invent a capacity model.

Copy the prompt below into Gainsight Copilot.

```text
Show me where the work sits across the CS team.
Group accounts by CSM. For each CSM, show the accounts, segment, renewal quarter, health, and open risk CTAs.
When two accounts look the same on ARR and segment, say which one needs more attention and why, using health and sentiment.
Flag any CSM whose renewals pile up in the same quarter.
If Staircase is connected, use sentiment as part of the load. If it is not connected, say so.
Do not invent hours, headcount, or capacity weights. If those are not in Gainsight, say so.
If a value is missing, say so. Do not invent numbers.
```
