# Risks across my book

Pipeline review. No customer name needed.

Copy the prompt below into Gainsight Copilot.

```text
Which of my accounts have open risk CTAs?
Group them by how urgent they look. For each, give the customer name, the risk, how long it has been open, priority, due date, renewal date if there is one, and the latest timeline note.
If Staircase is connected, add what the customer said that relates to the risk. If it is not connected, say so.
If a value is missing, say so. Do not invent numbers.
```
