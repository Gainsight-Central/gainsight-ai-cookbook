# Save plan

When an account is red and you need a plan before you write anything. Replace [customer name].

Copy the prompt below into Gainsight Copilot.

```text
[customer name] needs a save plan.
Tell me why it is at risk, who we need in the room and where each person stands, and the next three moves.
Draft the timeline note and the CTAs I would open. Do not post or create anything until I approve.
If Staircase is connected, use what the customer said and how sentiment has moved. If it is not connected, say so.
If a value is missing, say so. Do not invent numbers.
```
