# Success plan check

See the plan, or a proposal if there isn't one. Replace [customer name]. This does not create a plan.

Copy the prompt below into Gainsight Copilot.

```text
What is the success plan on [customer name]?
Show the current objectives, status, and what recent timeline activity says about each one.
If there is no plan, propose 3 to 5 objectives from the open CTAs, risks, and recent activity, and name which template fits. Do not create or update anything.
If Staircase is connected, include what the customer said they want. If it is not connected, say so.
If a value is missing, say so. Do not invent numbers.
```
