# CS capacity plan

For a CS leader or CS Ops planning books on live data instead of a spreadsheet. Fill in the inputs, or the prompt asks for them.

Copy the prompt below into Gainsight Copilot.

```text
Build a capacity plan for the CS team from Gainsight.
Use these inputs: hours per CSM per week [hours], buffer [percent], and hours per relationship by segment [segment hours]. If one is missing, ask me for it. Do not assume a value.
Weight each account's complexity by health, sentiment, and effort signals such as open risk CTAs, and say how you weighted them.
Show where the work is: hours, accounts, and CSMs needed by region, against current headcount.
Show CSMs needed versus on hand after expected churn and growth, if those are in Gainsight.
Recommend books that balance complexity and ARR and keep current owners where possible.
Flag any CSM whose renewals stack up in the same quarter.
If Staircase is connected, use sentiment in the complexity weight. If it is not connected, say so.
Do not reassign anything in Gainsight.
If a value is missing, say so. Do not invent numbers.
```
