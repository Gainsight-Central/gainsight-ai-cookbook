# Catch me up

The last 30 days on one account. Replace [customer name].

Copy the prompt below into Gainsight Copilot.

```text
Summarize the last 30 days on [customer name].
Give the highlights, open issues, decisions still waiting, and the next meeting if one is scheduled.
If Staircase is connected, include sentiment and what the customer said. If it is not connected, say so.
If a value is missing, say so. Do not invent numbers.
```
