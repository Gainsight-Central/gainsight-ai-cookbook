How these behave

Built so you can check the answer.

Told not to invent

Every prompt and skill says to label missing values. Verify high-stakes numbers in Gainsight.

You approve sends

Emails land as drafts. Nothing sends until you send it.

Writes are labeled

Exec prep posts automatically. Risk updates post to task Timelines. Weekly briefs write only when you click.

No extra access

These recipes don't widen what the connector can see. If a result looks wrong, stop and tell your admin.

Do I need to set anything up for Copilot?

No. Copy a prompt, paste it into Gainsight Copilot, and add the customer name. Staircase is included when it is already connected.

Can I use this in ChatGPT?

Yes. Claude, ChatGPT, and other agents that read a skill can run these once Gainsight is connected. Calendar, email, and search come from the tools that agent already has.

Do I need an ID?

No. When a prompt or skill needs an account, you give the customer name. The skills find the Gainsight records for you.

What if a risk flag looks wrong?

Check the date next to it. Stale or noisy signals are worth flagging to CS Ops.
